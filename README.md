
# Daily Expense Tracker

## About Project
This is a beginner-level Python project that
takes three expenses from the user, calculates
their total, and saves all expenses in a text file.

## Features
- Takes three expenses as input.
- Calculates total expenses.
- Saves expenses in Expense.txt.
- Reads and displays saved expenses.

## Technologies Used
- Python
- Variables
- User Input
- Arithmetic Operators
- File Handling

## How to Run
1. Install Python.
2. Download Expense.py.
3. Run the program.
4. Enter three expenses.
5. View the saved expenses.

Beginner
